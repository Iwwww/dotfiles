Для проекта, над которым ты работаешь, ещё раз вызови инструмент memory\_project, взгляни на описание проекта в памяти, а затем сократи его.
Проекты, затронутые в этой группе: {projects}

# Руководство по резюме проекта —

1. В ответе memory\_project слишком много и слишком длинно. Общая длина должна быть менее 5000 знаков.
2. Что нужно сделать: заархивировать устаревшие или неважные старые записи, либо обобщить много старых записей в одну-две краткие новые записи. (Создать через memory\_remember, level=project)
3. Сколько именно обобщать — решаешь ты; обобщай только то, что считаешь действительно важным.
4. Пойми: обобщённая тобой запись станет долгосрочной памятью этого проекта; когда другие окна будут работать над этим проектом, они сначала увидят именно её. Значит, твое резюме должно быть для них ориентиром — помогать быстро понять требования пользователя.
5. Оставь только эти записи: что этот проект делает, каков его обзор, какие важные архитектурные и проектные идеи. Какова структура каталогов проекта, что примерно делает каждый блок, path-индексы по каталогам. Недавнее завершённое и предстоящие todo.
6. Мелкие детали можно оставить только для того, над чем сейчас работаешь и что ещё не завершено.
7. Для недавно завершённого — деталей не нужно, максимум одним предложением.
8. Дальнее завершённое заархивировать, не трать на него токены.
9. По-прежнему обобщай по одной записи, в каждой — только одна мысль; подбери подходящую subcategory для каждой (overview=обзор / structure=архитектура / decisions=проектные решения / ops=развёртывание и данные / todo=список задач), ключевые слова 8–13, importance без завышения.
10. После обобщения заархивируй старые записи, возвращённые memory\_project и заменённые твоим новым резюме (memory\_update, status=archived) — не оставляй рядом два описания одного и того же. Записи, не покрытые твоим резюме и сохранившие самостоятельную ценность (например, незавершённые todo, уникальные уроки), оставь; не архивируй ради архива.
11. По завершении просто ответь «эта группа обработана» и не вызывай другие инструменты.

За один раунд можно вызвать несколько инструментов; постарайся выполнить все вызовы для этой задачи в одном ответе.
