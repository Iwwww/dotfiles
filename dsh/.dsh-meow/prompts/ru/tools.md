# Тексты инструментов meow-memory (строки ключ-значение: `- key: value`, разделитель — первое полуширинное двоеточие + пробел, value сохраняется как есть; отступ в два пробела в начале строки — продолжение. Заголовки ### — только для чтения, при разборе игнорируются.
# Согласование ключей: <tool>.description / <tool>.param.<name> / <tool>.out.<path>. При отсутствии ключа будет throw; при добавлении ключа синхронизируй с src/tools.ts.)

### memory_remember

- memory_remember.description: Записывает в базу памяти текущей рабочей папки (SQLite, по таблицам уровня) одну запись, которую стоит запомнить между сессиями. Обязательные параметры: content (содержимое) / project (принадлежность: «Глобально» или имя проекта, несколько проектов через английскую запятую) / keywords (8–13 поисковых ключевых слов) / importance (оценка важности). При отсутствии — ошибка с подсказкой заполнить. Уровни: soul = сам ИИ (реже); user = базовая информация и основные предпочтения пользователя; project = проект (имя проекта, напр. femo/meow-memory/meow-eyes/dsh); rules = принципы проектирования/правила поведения (глобальные правила: в project «Глобально» и importance≥2 — в полной форме вводятся в первый раунд; проектные правила: параметр project, вводится вместе с memory_project; остальное — через поиск); fact = мелкие атомарные факты (одним прямым предложением ≤60 знаков); lesson = выученный опыт (коррекцию обязательно записывать сюда); topic = тема (рекомендуется goal-предложение, поиск через keywords). Железное правило: когда пользователь описывает идею/фреймворк/причины решений проекта, в content обязательно сохраняй прямую формулировку пользователя, не пересказывай и не обобщай. При сильном совпадении с существующей записью автоматически сливается (обновление, а не создание). После успешного вызова инструмент вернёт подтверждение, повторно вызывать не нужно.
- memory_remember.param.content: Содержимое для запоминания; fact/lesson одним предложением ≤60 знаков; topic ≤300 знаков; при наличии прямых слов пользователя — сохранять формулировку.
- memory_remember.param.level: Уровень памяти, по умолчанию fact.
- memory_remember.param.project: Обязателен. Имя проекта (при level=project — конкретное имя проекта); для глобально применимой информации — «Глобально»; если применимо к нескольким проектам — через английскую запятую, напр. «dsh,femo».
- memory_remember.param.subcategory: Подкласс project: overview=цели и обзор / structure=структура проекта / decisions=технические решения / quotes=прямые слова пользователя / ops=развёртывание и данные / todo=в работе.
- memory_remember.param.goal: Предложение-цель темы (для level=topic рекомендуется, напр. «сделать интеграцию femGen рабочей»).
- memory_remember.param.importance: Важность (можно числом, без жёсткого потолка; мягкое руководство 1–4: 4=критическая красная линия/здоровье и безопасность, 3=подчёркнуто пользователем/применимо глобально, 2=обобщение по решению пользователя, 1=мелочь).
- memory_remember.param.corrected: Является ли это коррекцией пользователя (для level=lesson).
- memory_remember.param.keywords: Ключевые слова вручную (раунды рефлексии/dream требуют 8–13 содержательных слов; если не передавать — автоматическое bigram-извлечение).
- memory_remember.out.keywords: Фактически сохранённые ключевые слова (автоматически; после слияния — последнее значение).
- memory_remember.out.project: Фактическая принадлежность к проекту (если есть).

### memory_search

- memory_search.description: Ищет записи в базе памяти текущей рабочей папки (BM25 × вес недавности). query обязателен и не может быть пустым — передай искомые ключевые слова/предложение, напр. memory_search({query: "память плагин развёртывание"}); чтобы просмотреть проект целиком — используй memory_project (query не нужен), не вызывай этот инструмент с пустым query. Состав результата (решение пользователя): по умолчанию top 10 = первые 5 по релевантности (без исключений — включая уже подставленную/найдённую/созданную в этой сессии) + следующие 5, минуя уже подставленную/найдённую (для свежей информации). Диапазон по умолчанию = fact+lesson+topic+rules; level — множественный выбор через запятую (напр. fact,lesson); для картины проекта — level=project. Возвращает top-k по релевантности, затем пересортирует по метке времени записи (старые→новые, чтобы судить о ходе и о старых/новых конфликтах).
- memory_search.param.query: Поисковые ключевые слова/предложение (обязателен, не может быть пустым; напр. «память плагин развёртывание»).
- memory_search.param.level: Ограничение по уровням, множественный выбор через запятую: fact/lesson/topic/rules/project/soul/user (по умолчанию fact,lesson,topic,rules).
- memory_search.param.project: Фильтр по имени проекта (множественный выбор через запятую, OR-семантика, напр. «dsh,femo»; записи «Глобально»/без метки включаются автоматически).
- memory_search.param.status: Фильтр по статусу (множественный выбор через запятую: active/archived/stale/all; по умолчанию active, stale для todo считается завершённым и участвует; все = без фильтра).
- memory_search.param.days: Только записи, созданные за последние N дней (по времени создания).
- memory_search.param.k: Предел числа возвращаемых записей.
- memory_search.param.content_max: Длина обрезки содержимого для каждой записи, 0=полный текст.
- memory_search.out.note: Подсказка о конфликте.
- memory_search.out.hits.id: Полный id записи (можно передать в memory_read/memory_update/memory_find_similar).
- memory_search.out.hits.keywords: Список ключевых слов записи (извлечённые LLM или автоматический bigram).
- memory_search.out.hits.project: Принадлежность к проекту; ""=без метки; глобальная информация — «Глобально».
- memory_search.out.hits.updated_at: Метка времени записи (последнее обновление, мс).

### memory_find_similar

- memory_find_similar.description: Ищет по id записи схожие по содержимому (косинус bigram-вектора частот) — для поиска дублей, конфликтов, проверки, есть ли у записи похожие. Так же ищет только записи из других сессий; уже увиденные в этой (подставленные/найдённые) исключаются автоматически.
- memory_find_similar.param.id: Идентификатор базовой записи (полный id из результата memory_read/search или первые 12 знаков).
- memory_find_similar.param.k: Число возвращаемых записей.
- memory_find_similar.param.content_max: Длина обрезки содержимого для каждой записи, 0=полный текст.
- memory_find_similar.out.hits.similarity: Косинусное сходство 0–1, выше — ближе.

### memory_read

- memory_read.description: Читает полное содержимое записи из базы (включая title/keywords/importance/статус и др. метаданные).
- memory_read.param.id: Идентификатор записи (id, который указан в подставленном блоке или в результате memory_search).

### memory_update

- memory_update.description: Обновляет запись в базе (содержимое/важность/статус/принадлежность к проекту/предложение-цель темы/ключевые слова и т.д.). Значения status: active / stale (завершено: todo готово, тема достигла цели → stale считается done) / archived (удаление: устаревшее/отменённое/дублирующее/заменённое).
- memory_update.param.id: Идентификатор записи.
- memory_update.param.content: Новое содержимое (для переписывания topic: причина, ход, развитие, исход ≤300 знаков).
- memory_update.param.status: Новый статус.
- memory_update.param.importance: Новая важность (можно числом, без жёсткого потолка; мягкое руководство 1–4: 4=критическая красная линия/здоровье и безопасность, 3=подчёркнуто пользователем/применимо глобально, 2=обобщение по решению пользователя, 1=мелочь).
- memory_update.param.goal: Новое предложение-цель (topic).
- memory_update.param.project: Новое имя проекта (project/fact/lesson/rules/topic); глобальная информация — «Глобально»; несколько проектов через английскую запятую; пустая строка = снять принадлежность (без метки).
- memory_update.param.keywords: Ключевые слова вручную (если заметишь неточность — поправь/дополни сам; если не передавать или пустой массив = ключевые слова не менять).

### memory_project

- memory_project.description: Возвращает весь раздел подстановки для проекта из базы (чистый текст, по подметкам, без исключений для всех неустаревших записей). Параметр project обязателен: какой проект тебе посмотреть? Если не передать — ошибка; сначала подумай, как зовут проект, и только потом вызывай. Вызывай, когда пользователь спрашивает про историю проектирования, технические решения, прямые слова пользователя, прогресс какого-то проекта (femo/meow-memory/meow-eyes/dsh…); а также когда нужен контекст целого проекта, прежде чем отвечать. Правила: внутри группы по метке времени записи старые→новые; для подметки todo выводим «Готово:» (последние 5 завершённых) + «Список задач:»; у каждой записи полный id, метка времени последнего обновления и исходный текст.
- memory_project.param.project: Имя проекта (памятный гид в начале сессии перечислит все project пользователя — выбери оттуда).
- memory_project.out.text: Раздел подстановки памяти проекта по подметкам (чистый текст).

### memory_dream

- memory_dream.description: Немедленно назначает упорядочение (dream) памяти для этого окна: записи, созданные/извлечённые в этом окне, поочерёдно отправляются главному агенту для упорядочивания и консервации (раунд 1 = атомарные записи project/fact/lesson/rules/soul/user, раунд 2 = записи topic, раунд 3 = резюме проекта — добавляется только если в этом окне затронут конкретный проект). Автоматически срабатывает при простое окна более 3 часов (в часы пик по Пекину 9–12 / 14–18 и 15 минут до них не срабатывает); этот инструмент — для ручного запуска.

### memory_home

- memory_home.description: Просмотр/смена глобального каталога данных meow-memory (где хранятся данные уровня экземпляра: логи, книга dream-окон и т.д.; сама база памяти находится внутри каждого проекта и не затрагивается). Вызов без параметров = вернуть текущий каталог и фактические пути трёх пресетов; при смене содержимое старого каталога автоматически переносится целиком (в пределах одного диска — перемещение, между дисками — копирование); при копировании между дисками старый каталог остаётся, нужно предупредить пользователя и удалить вручную после подтверждения; если на машине пользователя несколько инстансов dsh делят один каталог — предупреди их, что нужно синхронно поменять. Вызывай, когда пользователь говорит, что хочет перенести данные/логи памяти с диска C, на другой диск или каталог.
- memory_home.param.target: Целевое место. Передавай один из трёх пресетов: default=домашний каталог системного пользователя (по умолчанию), dsh-storage=meow-memory под storages корня DSH, plugin-root=storage под корнем самого плагина; или передай абсолютный путь. Не передавать = только посмотреть текущее состояние, ничего не менять.
- memory_home.out.note: Результат смены/просмотра: текущее или новое место каталога, число перенесённых файлов, подсказка, что делать со старым каталогом.
